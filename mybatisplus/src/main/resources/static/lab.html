当前生效的 MP 插件

下面每一张卡片对应一个插件/特性，点按钮就能看到真实的 SQL 效果

① 三种并发控制扣库存

atomic = 原子 UPDATE（无锁）
pessimistic = SELECT ... FOR UPDATE 悲观锁
optimistic = @Version 乐观锁（冲突自动重试）
先把库存重置成指定值，再开多线程同时抢，三种方式都不会超卖。

② 自动填充 MetaObjectHandler

新增一条商品，代码里不写 createTime / updateTime， 由 MyMetaObjectHandler 回填；再改一次价格，看 updateTime 自动刷新。

③ 枚举 @EnumValue / IEnum

Java 里是 OrderStatus 枚举，数据库里存中文「待发货」，JSON 里是枚举名 WAIT。 依赖 {@code default-enum-type-handler} 配置。

④ 数据权限 DataPermission

「普通用户只能看自己的订单」不再写在业务代码里， 由 DataPermissionInterceptor 自动拼 {@code user_id = ?}；管理员不拼条件看全部。

⑤ 多租户 TenantLine

插入不写 tenant_id、查询不写 where tenant_id， 全由 TenantLineInnerInterceptor 处理（本项目只对 t_tenant_goods 生效，避免污染业务表）。

⑥ 动态表名（订单归档）

同一套 BikeOrderMapper，把上下文切成 t_order_2026， 写入和查询就都落到归档表，主表数据不受影响。

⑦ 批量插入三种写法对比

逐条 insert（n 次网络往返） vs saveBatch（JDBC Batch） vs insertBatchSomeColumn（一条 SQL 多组 VALUES，需要自定义 SqlInjector）。

⑧ 安全防护 BlockAttack / maxLimit

BlockAttackInnerInterceptor：不带 where 的 update/delete 直接拒绝。
PaginationInnerInterceptor.setMaxLimit(200)：size 再大也只返回 200 条。

⑨ 代码生成器（独立工具）

tools/CodeGenerator.java 是独立文件（不在 src 里，不参与编译）， 用 FastAutoGenerator 一次性生成 entity / mapper / service / controller。
mvn -B dependency:get -Dartifact=com.baomidou:mybatis-plus-generator:3.5.17 java -cp "<项目依赖>" tools/CodeGenerator.java # 生成内容： # entity / mapper / mapper.xml / service / serviceImpl / controller # 输出目录可改 OUTPUT_DIR，表可改 INCLUDE_TABLES
