@Valid + @RequestBody（失败抛异常 → 全局异常处理）

@Valid + BindingResult（自己处理错误，不抛异常）

校验分组 @Validated(Create/Update)

Spring 原生 Validator（@InitBinder + setValidator）

自定义约束：@Phone（注解 + PhoneValidator implements ConstraintValidator）， 用在 User.phone 字段上。
