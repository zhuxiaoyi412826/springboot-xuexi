② 请求参数绑定

简单参数 / Map / 数组集合

路径变量 / 请求头 / Cookie / 请求属性

POJO 绑定（含嵌套对象、集合、自定义类型、日期）

示例：/mvc/bind/pojo?username=zs&age=20&address.province=广东&address.city=深圳 &tags=a&tags=b&dept=10:研发部&birthday=2000-01-01&vipExpire=2030-12-31
dept 走自定义 Converter，vipExpire 走全局 @InitBinder 注册的 PropertyEditor。

@ModelAttribute + BindingResult（POST 表单）

@InitBinder("u") 设置了字段白名单：提交 id 会被忽略（防过度绑定）。
