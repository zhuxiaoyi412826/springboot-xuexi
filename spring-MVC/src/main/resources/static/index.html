知识点实验清单

每个页面都对应 Spring MVC 的一个知识域，页面上的按钮会真实调用后端接口， 右下（或下方）黑框里显示 HTTP 状态码与响应体。
① 返回值与视图

@ResponseBody、ModelAndView、forward、redirect、void、@ResponseStatus、自定义 ViewResolver

② 参数绑定

@RequestParam/@PathVariable/@RequestHeader/@CookieValue/@RequestAttribute/@ModelAttribute、POJO 嵌套、集合

③ 类型转换与格式化

自定义 Converter、Formatter、PropertyEditor、@DateTimeFormat/@NumberFormat、ConversionService

④ 数据校验

@Valid、@Validated 分组、自定义约束注解、BindingResult、Spring Validator

⑤ REST 接口

@RestController、ResponseEntity、HttpEntity/RequestEntity、@JsonView、consumes/produces

⑥ 异步请求

Callable、WebAsyncTask、DeferredResult、ResponseBodyEmitter、SSE、StreamingResponseBody

⑦ 文件上传下载

MultipartFile、多文件、@RequestPart+JSON、Part、三种下载方式

⑧ 会话与 Cookie

HttpSession、@SessionAttributes、FlashMap/RedirectAttributes、Cookie 读写删

⑨ 国际化

MessageSource、LocaleResolver、LocaleChangeInterceptor（?lang=en_US）

⑩ 异常处理

@ControllerAdvice、自定义 HandlerExceptionResolver、ResponseStatusException、ProblemDetail

⑪ 扩展点

自定义参数解析器、返回值处理器、HttpMessageConverter、内容协商

⑫ 路径与跨域

Ant 通配、正则占位符、params/headers/consumes 条件、CORS

⑬ 运行时观察

HandlerMapping 全量映射、拦截器/过滤器/监听器痕迹、在线会话数
