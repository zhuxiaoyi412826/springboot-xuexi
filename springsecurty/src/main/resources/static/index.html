视频小站 Spring Security 学习项目 登录 先去逛逛

在线视频浏览网站（Spring Security 全知识点演示）

两套静态页面

用户端
用户端页面
浏览/搜索/播放视频、点赞收藏、发评论、个人中心。 匿名即可浏览，写操作需要登录。
管理端
管理后台
用户管理、视频审核、评论管理、在线会话强制下线、登录日志。 需要 ROLE_ADMIN（否则跳 403）。

知识点体验入口

知识点怎么体验
表单登录 / 记住我 / 匿名访问user/login.html（勾选「记住我」后关闭浏览器再打开仍保持登录）
HTTP Basiccurl -u admin:admin123 http://localhost:8084/app/basic/me
HTTP Digestcurl --digest -u admin:admin123 http://localhost:8084/digest/me
OAuth2 资源服务器（JWT）先 POST /api/auth/token 取令牌，再 -H "Authorization: Bearer xxx" /api/videos
自定义认证（API Key）-H "X-API-Key: video-site-api-key-8888" http://localhost:8084/api/ping
URL 级 / 方法级 / 对象级权限用普通账号访问 admin/index.html → 403；删除他人评论 → 403
并发登录与强制下线两个浏览器登录同一账号（最多 2 个），管理后台「强制下线」
CSRF不带 X-XSRF-TOKEN 直接 POST /app/comments/add → 403
