登录

第三方登录按钮由 /app/auth/oauth2-clients 动态渲染：没配置 client-id 时不会出现。
登录请求会带上 CSRF Token（X-XSRF-TOKEN 头），服务端已开启 CSRF 防护。

其它认证方式（命令行体验）

方式命令
HTTP Basiccurl -i -u admin:admin123 http://localhost:8084/app/basic/me
HTTP Digestcurl -i --digest -u admin:admin123 http://localhost:8084/digest/me
OAuth2 资源服务器(JWT) curl -X POST http://localhost:8084/api/auth/token -H "Content-Type: application/json" -d '{"username":"admin","password":"admin123"}'
自定义 API Key curl -i -H "X-API-Key: video-site-api-key-8888" http://localhost:8084/api/ping
